# RupeeFlow — Personal Finance Experience

A modern, responsive React + Vite demo for managing a ₹10,000 budget across 30 days.

## Stack
- React 18 + Vite
- Recharts for balance and category visualisations
- Lucide React icons
- Custom responsive CSS
- LocalStorage persistence (demo data stays in this browser)

## Run locally
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Features
- Available balance, daily allowance, monthly forecast, financial risk and money-health score
- Transaction feed with add and delete
- Category spend breakdown and balance forecast chart
- Savings goals and transfers to goals
- Subscription toggles that recalculate recurring commitments
- Decision Lab for purchase, savings and unexpected-expense simulations
- Responsive layout and local persistence
- Reset demo action

## Notes
This is a front-end demo, not a bank-connected product. All data is illustrative and stored in the browser. Financial risk and health scores are simple educational heuristics, not regulated financial advice.
